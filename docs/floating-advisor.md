# Global floating advisor

Status: implemented locally, 17 September 2026. Not part of the previously deployed full-20260916 release.

One body-level host in `overview-advisor.js` owns the authenticated `/advisor/` frame. The main router supplies page, scope, theme and period context. Route changes retain the frame, draft, conversation and voice connection; scope changes dispose it. Existing authenticated endpoints and sandbox boundaries are unchanged.

The outer chat surface is transparent; message bubbles, composer, generated canvas, activity and history use the existing theme's surface colors. Normal chat sizes to its content, capped for scrolling. Expanded chat retains history and active conversation. The header grip moves chat; the orb itself moves voice. Arrow keys move 16px; Home or double-click resets position. Stored coordinates contain no conversation or financial data. Viewport clamping and mobile bottom-navigation clearance keep controls reachable.

The floating orb imports the same bundled, pinned Libraries.dev engine as the composer. It paints the supported 64px presets scaled to a crisp 112px canvas; state mapping is shared. The glow/reflection underneath is a CSS layer, not a separate orb implementation. Visibility and reduced-motion preferences suspend unnecessary animation.

## Optional AI Glass — 17 September 2026

Appearance now persists `aiGlass` alongside existing theme/language preferences. Default is off. Color selection remains independent. The locally vendored MIT library is rizzytoday/liquid-glass at commit `841af14fb3eb9653d24aacf4eb049c9f389db1ef`; license and attribution accompany it. The only vendor patch bounds geometry-map cache at 64 entries. There is no runtime CDN or remote image fetch.

The same-origin chat iframe cannot sample the parent backdrop directly. `advisor-glass.js` therefore mirrors only visible surface geometry into noninteractive parent-page panes below the frame. Actual text, controls, and isolated generated artifacts stay in their existing DOM. The geometry canvas contains gradients only. Visible surfaces are capped at 32; hidden, minimized, disabled and disposed panes release their filters/observers. Scroll and resize keep clipping aligned. Reduced-transparency skips optical layers; Safari/Firefox use the vendor blur fallback (not independently browser-tested here).
