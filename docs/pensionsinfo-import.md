Originals are Data Protection ciphertext in the existing private workspace SQL database, scoped by hosting key ring, mode and Demo scope. Existing `/home/Banking` keys/protection certificate remain necessary for recovery. HTTP returns explicit DTOs without `protectedOriginal`, internal `previewJson`, filenames or PDF metadata. No raw report text/bytes enter advisor tools, logs, OCR/LLM services or instructions. Existing accepted capital facts remain ordinary financial context.

[PdfPig 0.1.16](https://www.nuget.org/packages/PdfPig/0.1.16), a pure managed Linux-compatible Apache-2.0 dependency, was checked against its [versioned primary documentation](https://github.com/UglyToad/PdfPig/tree/v0.1.16). Extraction groups words by coordinates instead of assuming `page.Text` reading order. Locks/audit remain enabled and upstream notices ship with the package.

A separate `--pension-pdf-worker` starts before web configuration, with runtime lookup variables only, disabled CLR diagnostics, a 256 MiB GC cap, 384 MiB working-set check, one concurrent parser and 20-second deadline. Input/output and whole-process-tree cancellation are bounded. Limits: 8 MiB PDF, 80 pages, 60,000 letters/page, 600,000 total letters, 512,000 output characters; JSON 60 KB; reviewed approval 768,000 bytes. Encrypted, blank/scanned, malformed, excessive and unrecognized files return safe outcomes. No normal Linux business backend or local data fallback is introduced.

The worker observes bounded-reader failures while the child is running: an oversized result must return `PENSION_PDF_OUTPUT_LIMIT` and kill the child, rather than leave it blocked on a full pipe until a misleading timeout. Internal JSON omits null properties and computed confidence text; the parent reconstructs these without changing the full review/API model or any extracted fact. The output cap is unchanged. A strictly decoded stderr progress channel accepts only fixed processing stages and bounded page/letter/timing counts; only those fields and a fixed outcome reach the parent logger. Raw stderr, source text, values, font names, file hashes/metadata and identifiers are never forwarded. Progress records do not enter the financial model or advisor context.

Cloud-only synthetic measurements on 16 October reproduced the old pipe deadlock at 20 seconds although parsing took about 0.2 seconds; the corrected boundary rejects that oversized output in under one second. Single-core-affinity Linux measurements with the existing child limits completed independent Type3 fixtures in about 1.4 seconds (46 pages) and 1.8 seconds (80 pages), including 100 synthetic Type3 fonts, large glyph programs, valid font-level bounding boxes and missing descriptor bounding boxes. These fixtures and paired-scenario/capital/contribution/insurance fixtures are regression evidence only.
